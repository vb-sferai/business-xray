# render.md — как сверстать business-xray.html

Читаешь этот файл только на последнем шаге, когда `business-xray.md` уже записан:
шапка и все 7 разделов фактуры заполнены.

## Шаги

1. Скопируй `template.html` в новый файл `business-xray.html` в той же папке.
2. Замени каждую заглушку текстом фактуры. Заглушку ищи поиском по слову
   `ЗАГЛУШКА`; нужная длина подсказана в самой заглушке.
3. Абзац под заголовком цепочки — первая строка раздела 1 фактуры.
4. Повторяющиеся блоки размножь по числу элементов фактуры, лишние образцы удали:
   - `<article class="node">` — 5 узлов цепочки: рынок, клиент и его работа,
     ценность, экономика, каналы;
   - `<article class="cand">` — 3–5 кандидатов, номера `01, 02, …` по порядку;
   - `<article class="bet">` — 2–3 ставки, номера по порядку;
   - пункты списков фактуры (подготовить заранее, что не делаем, дальше) —
     каждый в свой `<li>`.
5. Статус узла — слово в чип и класс на том же `<article class="node">`:
   `работает` → `st-ok`, `можно усилить` → `st-weak`, `точка роста` → `st-broken`,
   `нет данных` → `st-none`.
6. Полоски эффекта и простоты: на каждом `<div class="meter" style="--v:N">`
   поставь N = 1, 2 или 3 из фактуры.
7. Часы в месяц — в `<span class="num mono">` ставь значение из фактуры как есть:
   число, «≈ число» или «—». Пояснения из ячейки в HTML не переносить.
8. Промпт из раздела 6 фактуры вставь внутрь `<code>` блока «Первый промпт
   агенту» как есть, с переносами строк.
   Во всём вставленном тексте экранируй `&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`.
9. Разметку, стили и скрипт шаблона не меняй и ничего не «улучшай». Удалить
   можно только комментарий в начале файла. Снимок цепочки на обложке и матрицу
   «эффект × простота» над кандидатами рисует скрипт шаблона из заполненных
   узлов и полосок — руками их не добавляй. Поэтому класс статуса на каждом
   узле (шаг 5) и `--v` на каждой полоске (шаг 6) обязательны.
10. Пустой раздел фактуры — удали его блок целиком: `<section>` от открывающего
    тега до закрывающего (или `<footer class="final">` для раздела 7).

## Критерий готовности

- поиск слова `ЗАГЛУШКА` по `business-xray.html` даёт 0 совпадений;
- файл открывается в браузере и показывает все разделы фактуры.

## Как отдать человеку

Дай путь к `business-xray.html` и скажи: «Откройте файл в браузере,
Ctrl+P (Cmd+P на Mac) → Сохранить как PDF». Кнопка «Скопировать» работает
в браузере, в PDF она не попадает.
